# Evidence Studio: public website

The built website of the Extractive Writing Harness, served by GitHub Pages at
https://manish-genai.github.io/paper-writing-site/.

This repository holds only generated files: the public edition of the web interface, its data and the
public edition of the report (`downloads/`). It is published from a private source repository with
`scripts/publish_site.sh`; edit the source there, not here.

The public edition leaves out per-professor data (professor lists, dossiers, topic leaders and lab style
profiles), because that data is partly derived from CSRankings data, whose licence (CC BY-NC-ND 4.0)
does not allow sharing modified versions. The writer's example brief is a made-up project.
